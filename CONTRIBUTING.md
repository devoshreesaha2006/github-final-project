# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. **Fork** the repository
2. **Clone** your forked repository locally
3. **Create a new branch** for your contribution:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and commit them:
   ```bash
   git commit -m "Add: description of your changes"
   ```
5. **Push** the branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request** against the main branch of this repository

## Types of Contributions Welcome

- 🐛 **Bug Reports** – Found a bug? Open an issue with steps to reproduce
- 🔧 **Bug Fixes** – Submit a PR with the fix and reference the issue
- 📝 **Documentation Improvements** – Improve the README, add examples, fix typos
- ✨ **Enhancements** – Suggest or implement new features
- 💡 **Ideas** – Share your ideas by opening a discussion or issue

## Code Standards

- Write clear, readable Bash code
- Add comments to explain non-obvious logic
- Test your changes before submitting

## Reporting Issues

When reporting bugs, please include:
- A clear title and description
- Steps to reproduce the issue
- Expected vs actual behavior
- Your operating system and Bash version
